## 运行

在项目目录执行：

```powershell
python -m pip install -r requirements.txt
python -m unittest -v
python -m src.run
```

首次运行下载行情并在 data/raw/snapshots 保存带 UTC 下载时间的 JSON 原始快照和 SHA256 校验文件；
以后默认读取 active.json 指向的快照，不联网更新。截止日期固定在 src/config.py，目前为 2026-09-17。
需要更新时，修改日期后显式执行 python -m src.run --refresh。旧快照保留。
指定快照可执行 python -m src.run --snapshot data/raw/snapshots/文件名.json。
日期和标的配置必须与快照一致；规则参数可以变更。

网络不可用时，准备 7 个代码命名的 CSV（如 510300.SS.csv），执行：
```powershell
python -m src.run --import-dir data/raw
```
CSV 必须包含 Date、Open、Close、Volume；Open 和 Close 必须都是同一口径前复权价。
仅有收盘价的旧格式不再接受。导入者须确认复权口径；程序无法凭数值辨别未复权开盘价。
快照记录导入时间与源文件哈希，但不把导入时间冒充行情下载时间。

## 执行与研究假设

- 月末收盘计算 20/60/120 日收益等权平均，下一交易日开盘按排名买入前 2 名。
- 旧持仓获得前收盘到成交开盘的盈亏，新持仓获得开盘到收盘的盈亏。
- 月内保持复权单位数量不变，权重自然漂移；月末即使入选名单不变，也按实际仓位再平衡。
- 初始资金 100 万；单边交易金额乘 5 bps，买卖都收费；求解扣费后能自融资的目标配置。
- 使用可分割的“复权单位”，不是交易所真实份额。分红效果由数据商复权序列表示，不另加现金分红。
  此模型未模拟整手、最小佣金、涨跌停排队或大额冲击。复权总收益口径应进一步与基金公告/第二数据源核验。
- 缺失收盘价只允许前向填充用于估值，不用于信号或成交；信号窗口内存在缺失就排除该标的。
- 调仓涉及的任一持仓或目标标的开盘价缺失、成交量非正，则整笔调仓跳过，保留旧仓位至下一个月度信号。
  日成交量是事后可交易代理，不能保证开盘瞬间一定成交；这仍是研究模拟的局限。
- 标的池是当前预先选择的固定池，存在事后选择偏差。数据日期采用各 ETF 已观察日期的并集，
  未覆盖全市场都缺失的交易日；正式研究还应与交易所日历交叉核验。

## 四个同口径组合

- momentum：纯相对动量。
- momentum_cash：有效候选至少 TOP_N 个、且所有有效分数严格小于零时持现金；否则执行原规则。
  不足 TOP_N 时不产生调仓信号。零分不触发现金条件。
- benchmark_equal：7 ETF 在共同起点开盘初始等权买入，之后持有不调仓。
- benchmark_csi300：同日起点开盘买入沪深300 ETF，之后持有不调仓。

共同起点为第一个有有效月度信号、且全部标的具备开盘价和正成交量的执行日。
四组合使用相同费用、样本区间；现金收益率与夏普无风险利率均为 0。
等权基准帮助识别跨资产配置的影响，但策略差异还包含集中度及再平衡效应，不能单独证明动量因果作用。

## 指标与输出

标准夏普 = 日收益均值 / 日收益样本标准差 × sqrt(252)，rf=0。
几何年化收益 / 年化波动另命名 return_vol_ratio。最大回撤把最初净值 1 纳入峰值，包含首日亏损。
年化使用 252 个观测交易日；daily_win_rate 为正收益天数/全部样本天数，包含零收益日。
调仓次数为实际执行的配置事件（可含零交易）；trade_count 是非零资产买卖笔数。
不假设期末清仓，因此期末没有额外卖出费用。

每次运行创建独立 outputs/run_时间戳 目录，包含：
- performance_summary.csv、portfolio_returns.csv、equity_curve.png。
- run_metadata.json：数据日期/下载或导入时间、复权口径、快照哈希、代码哈希、参数、运行版本。
- 每个组合子目录：每日净值与现金、每日持仓与权重、买卖流水、执行/跳过记录、完整月末排名。
- holdings 中各资产 return_contribution 之和减去当日 transaction_cost 等于组合净收益。
  跨期归因请累计 asset_pnl 金额；不能直接把日贡献百分比相加当成累计收益贡献。

末尾未执行的月末/样本尾日排名会保留，trade_date 为空；不能将这些记录计作实际调仓。

